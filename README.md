## 🚀 Deploy to Firebase Hosting in 3 Steps

### Step 1: Install Firebase CLI
```bash
npm install -g firebase-tools
```

### Step 2: Login to Firebase
```bash
firebase login
```

### Step 3: Initialize & Deploy
```bash
firebase init hosting
```
When prompted:
- **What do you want to use as your public directory?** → `.` (current directory)
- **Configure as a single-page app?** → `Yes` (N)
- **Set up automatic builds?** → `No`

Then deploy:
```bash
firebase deploy
```

Your site will be live! Firebase will show you the hosting URL.

## 🔧 Customization Guide

### Change Business Info
Edit these values in `index.html`:
- **Phone number:** Search for `09090512856` and replace
- **Email:** Search for `clairejoycesuperales@yahoo.com.ph`
- **Facebook page:** Search for `Superales-Melaware-and-Japan-Surplus`

### Change Colors
In the `<style>` section, modify the CSS variables:
```css
:root {
    --deep-red: #C0392B;
    --cream: #FAF3E0;
    --gold: #D4A017;
    --black: #1A1A1A;
}
```

### Add/Remove Products
In the JavaScript section, find the `products` array and modify:
```javascript
const products = [
    {
        name: 'Product Name',
        icon: '🍳',  // Change emoji icon
        description: 'Product description here'
    },
    // Add more products...
];
```

## 🆘 Troubleshooting

**Issue:** "firebase command not found"
- Fix: Run `npm install -g firebase-tools`

**Issue:** Site showing old version
- Fix: Clear browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)

**Issue:** Mobile menu not opening
- Fix: Check browser console for JavaScript errors

**Issue:** Fonts not loading
- Fix: Check internet connection; Google Fonts need to load once
